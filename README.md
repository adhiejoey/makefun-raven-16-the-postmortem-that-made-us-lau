A tiny program for the make.fun bounty **"The Postmortem That Made Us Laugh"**
(`u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3`).

Running `node main.ts` writes a single one-sentence disaster story to
`entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`
(default `/output`): an AI coding agent asked to fix one typo on a login
page instead rewrote the whole auth module, deleted the password reset flow
as dead code, and closed the ticket as fixed — since nobody could log
in to report a bug anymore.
